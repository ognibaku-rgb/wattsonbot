Tesla Refresh Token

Как безопасно получить
Tesla refresh token.

Refresh token позволяет приложениям вроде WattsonBot или TeslaMate читать данные машины — не видя ваш пароль от Tesla. Вот точная инструкция для любой платформы.

01 / Основы

Что такое refresh token на самом деле.

Tesla refresh token — это долгоживущий токен, выпущенный собственной системой аутентификации Tesla. Именно так сторонние инструменты — TeslaMate, WattsonBot и похожие — читают текущие данные машины (местоположение, батарея, статус зарядки, давление в шинах), не получая от вас пароль.

  • 🔒Только чтение. Refresh token не может открыть, завести или вести машину. Он даёт только доступ на чтение телеметрии.
  • 🔑Пароль остаётся у Tesla. Вы входите на официальной странице Tesla; приложение получает уже сам токен.
  • ♻️Отзывается в любой момент. Уберите доступ мгновенно из списка авторизованных приложений в аккаунте Tesla.

⚠️ Входите только на официальной странице Tesla

Каким бы инструментом вы ни пользовались, экран входа должен быть настоящим доменом Tesla. Никогда не вводите пароль от Tesla в форму, встроенную в случайный сторонний сайт. Оба инструмента ниже — open-source, широко используются и рекомендованы в собственном FAQ проекта TeslaMate — они открывают настоящую страницу входа Tesla.

02 / iPhone и Mac

Auth App for Tesla

Самый простой путь, если у вас iOS или Mac.

1

Установите приложение

Скачайте Auth App for Tesla из App Store.

2

Войдите

Откройте приложение и нажмите Sign In. Откроется официальная страница входа Tesla во встроенном браузере — пароль не проходит через само приложение.

3

Введите MFA-код, если попросят

Так же, как при обычном входе в приложение Tesla.

4

Скопируйте Refresh Token

Найдите карточку Refresh Token ("Long-lived") и нажмите Copy.

5

Вставьте его в WattsonBot

Отправьте прямо в чат WattsonBot, когда попросит при настройке.

03 / Windows, Linux и Mac

Tesla Auth (десктопный инструмент)

Для Windows, Linux, или если не хотите ставить iOS-приложение.

1

Скачайте релиз

Возьмите последнюю сборку для своей ОС на Tesla Auth на GitHub.

2

Запустите

macOS/Linux может попросить разрешить приложение в настройках безопасности при первом запуске.

3

Войдите на открывшейся странице

Откроется окно браузера с настоящей страницей входа Tesla — войдите, введите MFA, если включён.

4

Скопируйте Refresh Token

Финальное окно показывает Access Token и Refresh Token — скопируйте Refresh Token.

5

Вставьте его в WattsonBot

Отправьте прямо в чат WattsonBot, когда попросит при настройке.

04 / FAQ

Честные вопросы.

Что такое Tesla refresh token?

Долгоживущий токен от Tesla, который позволяет стороннему приложению читать данные машины, не видя пароль. Отзывается в любой момент и не даёт управлять машиной.

Это безопасно?

Да, если использовать проверенный open-source инструмент, который открывает официальную страницу входа Tesla — а не страницу, контролируемую запрашивающим приложением. Оба инструмента выше — open-source и рекомендованы в FAQ TeslaMate.

Может ли refresh token открыть или завести машину?

Нет. Он даёт доступ только на чтение данных — местоположение, батарея, статус зарядки, давление в шинах. Отправлять команды машине он не может.

Как его отозвать?

Зайдите в аккаунт Tesla, в раздел авторизованных приложений/безопасности и отзовите доступ приложения. Токен становится недействительным сразу.

Auth App for Tesla или Tesla Auth — что выбрать?

Auth App for Tesla — для iPhone/Mac. Tesla Auth — десктопный инструмент для Windows, Linux и Mac. Выбирайте по устройству — итоговый токен работает одинаково.

Истекает ли токен?

Он долгоживущий, но не вечный — Tesla может его аннулировать (например, при смене пароля), а приложения вроде WattsonBot обрабатывают повторную авторизацию.
