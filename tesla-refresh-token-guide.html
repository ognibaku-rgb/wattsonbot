How to get a Tesla
refresh token safely.

A refresh token lets apps like WattsonBot or TeslaMate read your car's data — without ever seeing your Tesla password. Here's exactly how to get one, on any platform.

iPhone / Mac guide Windows / Linux guide
01 / Background

What a refresh token actually is.

A Tesla refresh token is a long-lived credential issued by Tesla's own authentication system. It's how third-party tools — TeslaMate, WattsonBot, and similar — read your car's live data (location, battery, charging state, tyre pressure) without you handing over your password to a third party.

  • 🔒Read-only. A refresh token cannot unlock, start, or drive the car. It only grants read access to vehicle telemetry.
  • 🔑Your password stays with Tesla. You authenticate on Tesla's own login page; the token is what the app receives afterward.
  • ♻️Revocable anytime. Remove access instantly from your Tesla account's authorized-apps list.

⚠️ Only ever log in on Tesla's own page

Whichever tool you use, the login screen it opens must be Tesla's real domain. Never type your Tesla password into a form embedded in a random third-party site. The two tools below are open-source, widely used, and recommended by the TeslaMate project's own FAQ — they open Tesla's actual login page for you.

02 / iPhone & Mac

Auth App for Tesla

The simplest route if you're on iOS or Mac.

1

Install the app

Get Auth App for Tesla from the App Store.

2

Sign in

Open the app and tap Sign In. This opens Tesla's own login page in an in-app browser — your password never passes through the app itself.

3

Enter MFA if prompted

Same as logging into the Tesla app normally.

4

Copy the Refresh Token

Find the card labeled Refresh Token ("Long-lived") and tap Copy.

5

Paste it into WattsonBot

Send it directly in the WattsonBot chat when prompted during setup.

03 / Windows, Linux & Mac

Tesla Auth (desktop tool)

For Windows, Linux, or if you'd rather not install an iOS app.

1

Download the release

Grab the latest build for your OS from Tesla Auth on GitHub.

2

Run it

3

Log in on the page it opens

It opens a browser window to Tesla's actual login page — sign in, enter MFA if enabled.

4

Copy the Refresh Token

The final window shows both an Access Token and a Refresh Token — copy the Refresh Token.

04 / FAQ

Fair questions.

What is a Tesla refresh token?

A long-lived credential issued by Tesla that lets a third-party app read your car's data without ever seeing your password. It can be revoked anytime and cannot control the car.

Is it safe?

Yes, when you use a reputable open-source tool that logs you in on Tesla's own official page — never a page controlled by the requesting app. Both tools above are open-source and recommended by TeslaMate's own FAQ.

Can a refresh token unlock or drive my Tesla?

No. It grants read-only access to vehicle data — location, battery, charging state, tyre pressure. It cannot send commands to the car.

How do I revoke it?

Log in to your Tesla Account page, go to the authorized-apps / security section, and revoke access for the app. This invalidates the token immediately.

Auth App for Tesla or Tesla Auth — which one?

Auth App for Tesla is for iPhone/Mac. Tesla Auth is a desktop tool for Windows, Linux and Mac. Pick whichever matches your device — the resulting token works the same either way.

Does the token expire?

It's long-lived but not permanent — Tesla can invalidate it (e.g. after a password change), and apps that use it, like WattsonBot, handle re-authentication if that happens.
